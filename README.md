# Adventure Buddha website

Trip website, online booking and team dashboard for Adventure Buddha (group trips from Bangalore).

- Public site: server-rendered trip pages (SEO friendly), booking with UPI or Razorpay, enquiries and callbacks
- Team dashboard at `/admin/`: trips, dates, itineraries, photos, bookings, passenger lists, enquiries, missed checkouts, customers, coupons, team logins with roles
- Runs on Cloudflare Pages + D1

See **SETUP.md** for step-by-step setup.
